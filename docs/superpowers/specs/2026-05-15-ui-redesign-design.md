# Bonjour Minecraft Launcher — UI 重新设计规格书

**日期：** 2026-05-15  
**状态：** 已确认  
**版本：** 1.0

---

## 1. 背景与动机

当前启动器的 UI 呈现强烈的「AI 味」—— 毛玻璃泛滥（glassmorphism）、千篇一律的渐变暗色背景、过度的 framer-motion spring 弹性动画、模板化的暗色模式。虽然技术实现完整（12 套主题预设、无障碍系统、动态背景等），但在视觉独特性和风格辨识度上严重不足。

**目标：** 推倒重来，打造一个独特、吸引人、经久耐用、功能丰富的启动器 UI。

---

## 2. 核心设计概念

### 2.1 双主题系统

启动器提供两套截然不同的视觉主题，用户可在二者之间切换：

| 主题 | 状态 | 核心美学 |
|------|------|----------|
| **卡带未来主义** (Cassette Futurism) | **默认** | 80-90s 电子产品 + CRT 终端 + 物理按钮隐喻 |
| **侘寂工坊** (Wabi-Sabi Workshop) | 可切换 | 纸/木/墨触感 + 日本传统色 + 手作工坊温暖 |

### 2.2 设计哲学转变

| 旧 (AI 味) | 新 (独特风格) |
|---|---|
| 毛玻璃 backdrop-blur | 纯色面板 + 边框（卡带）/ 纸片阴影（侘寂） |
| framer-motion spring 弹性动画 | 线性/step-based 过渡 |
| 大圆角 14px-20px | 2px（卡带）/ 1px（侘寂） |
| 渐变背景 + 粒子/aurora/waves | CRT 扫描线覆盖层 / 和纸纤维纹理 |
| Lucide 通用图标 | 像素图标 16×16 / 细线 SVG |
| 强一致双主题（浅/深只是色值翻转） | 异质双主题（两个主题从材质到字体完全不同） |

## 3. 主题一：卡带未来主义 (Cassette Futurism) — 默认

### 3.1 底色调色板

| 角色 | 色值 | 用途 |
|------|------|------|
| 主底色 | `#0D0E0A` | 全局背景，不是纯黑，微带暖绿底模拟 CRT 磷光余晖 |
| 面板/卡片 | `#151712` | 表面层 |
| 边框 | `#2A2E1A` / `#3A4A1A` | 面板边框，活跃项边框用主色 |
| 输入框 | `#1A1C12` | 表单域背景 |

### 3.2 功能色

| 角色 | 色值 | 用途 |
|------|------|------|
| 主强调色 | `#E8C547` (琥珀黄) | 活跃元素、标题、按钮边框、导航高亮 |
| 主色辉光 | `text-shadow: 0 0 8px rgba(232,197,71,0.5)` | 始终伴随主色 |
| 次要文字 | `#8B9B3A` (苔绿) | 次级信息、标签 |
| 三级文字 | `#5A7A3A` / `#6A7A2A` | 禁用态、辅助信息 |
| 成功 | `#4A8B3A` | 状态指示 |
| 错误 | `#E85147` (CRT 红) | 错误、危险操作 |
| 信息 | `#3A5AE8` (终端蓝) | 信息提示 |

### 3.3 字体

- **全局 UI 字体：** JetBrains Mono（免费开源等宽字体）
- **字号基准：** 14px 正文，10px 辅助，8px 标签
- **应用范围：** 所有界面文字，包括按钮、标签、标题、数据展示

### 3.4 导航

- **形式：** 底部栏，面板按键式
- **标签格式：** `[HOME]` `[VERS]` `[MODS]` `[WRLD]` `[SET]` — 4 字符括号包裹
- **活跃态：** 琥珀色边框 + glow 效果
- **非活跃态：** 苔绿色文字 + 暗绿边框

### 3.5 特殊设计元素

- **播放按钮：** 大字 `▶ START`，发光琥珀边框，底部提示 `PRESS [ENTER] OR CLICK`
- **状态栏：** 顶部 CPU/RAM/DISK/JAVA 一行式状态
- **CRT 扫描线叠加层：** 静态半透明水平条纹覆盖全屏（opacity ~0.03）
- **窗口控制：** 保留红黄绿交通灯，但使用像素化圆点

## 5. 主题切换机制

### 5.1 切换入口

- 设置面板中的主题卡片
- 键盘快捷键 `Ctrl+T`

### 5.2 动画流程（仪式感过渡，总时长 ~1.2s）

**卡带 → 侘寂：**
1. CRT 关机（0.4s）：屏幕从上下向中间收缩为一条亮线，然后熄灭
2. 中间态（0.3s）：全黑，中央出现纸门拉开隐喻动画
3. 展开（0.5s）：纸门从中间向两侧推开，露出侘寂界面

**侘寂 → 卡带：**
1. 纸门合拢（0.4s）：两侧纸门向中间关闭
2. 中间态（0.3s）：全黑，中央出现 CRT 开机光点
3. CRT 开机（0.5s）：扫描线从上往下扫过，显示卡带界面

### 5.3 实现策略

- 使用 CSS 自定义属性（`--theme-*`）驱动所有颜色值
- 每个主题一套完整的 CSS 变量定义
- 主题切换 = 替换 `:root` / `[data-theme]` 下的变量值
- 字体通过 `data-theme` 属性切换
- 纹理叠加层通过 CSS `::after` 伪元素实现

## 6. 通用设计原则

### 6.1 布局架构

- 底部导航 + 页面切换（保持现有架构）
- 两个主题共享相同的 React 组件树和数据流
- 样式层通过 CSS 变量和 `data-theme` 属性分离

### 6.2 动画语言

- 废除 framer-motion `spring` 动画
- 页面切换：opacity + 平移动画，`ease-out`，~200ms
- UI 交互反馈：`step-start` 即时响应，不拖泥带水
- 数据加载：卡带 = `typing` 逐字出现效果，侘寂 = 微妙 `fade-in`

### 6.3 圆角策略

- 卡带主题：`border-radius: 2px` 全局
- 侘寂工坊：`border-radius: 1px` 全局
- 按钮/输入框同规则，不作区分

### 6.4 图标

- 卡带主题：自制 16×16 像素图标（Minecraft 方块风格）
- 侘寂工坊：细线 SVG，配色跟随主题
- 移除 Lucide React 图标库依赖

### 6.5 现有系统的处理

- **12 套主题预设：** 保留但降级为设置中的辅助选项，不作为主要卖点
- **无障碍系统：** 保留（高对比度/减少动画/大文本/键盘焦点/色盲模式），适配新主题
- **多窗口支持：** 保留，各窗口独立跟随主题
- **i18n 国际化：** 保留
- **Zustand 状态管理：** 保留

## 8. 约束与注意事项

- 项目使用 Tauri v2 桌面框架，窗口支持透明背景（`transparent: true`）
- 自定义窗口装饰（`decorations: false`），无原生标题栏
- 多窗口架构（overlay/settings/mods-browser/launch-log/map-preview），各窗口主题需同步
- 必须保持对现有 5 个 Zustand store 的兼容
- 后台 Rust 服务和 API 桥接不受影响
- 国际化（4 种语言）需覆盖新 UI 文案
