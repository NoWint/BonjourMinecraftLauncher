# Bonjour Minecraft 启动器 - 设计文档

## 设计理念

**"影院级沉浸式体验"**

融合 Apple TV 的沉浸式全屏美学与 Epic Games Store 的游戏仪式感，打造一个令人惊艳的 Minecraft 启动器。内容为王，界面隐形，每个像素都为游戏体验服务。

---

## 核心设计原则

1. **全屏沉浸** - 内容占满整个视口，无多余边框
2. **极简导航** - 底部图标导航，释放顶部空间
3. **玻璃质感** - 超轻玻璃效果，信息浮于内容之上
4. **大胆排版** - 巨大的版本号，清晰的层级
5. **流畅动效** - 每个交互都有意义，流畅自然

## 页面设计

### 主页 (Home)
```
布局：
- 背景：当前版本的游戏场景图（全屏，带视差）
- 中央：大版本卡片
  - 版本号：48px，粗体
  - 加载器：24px，次级文字
  - 统计信息：水平排列
  - 启动按钮：居中底部
- 底部：版本切换指示器（小圆点）

交互：
- 左右滑动：切换版本
- 点击启动：按钮扩展动画
- 背景：跟随鼠标轻微视差
```

### 游戏库 (Library)
```
布局：
- 顶部：标题 "游戏库" + 添加按钮
- 主体：横向滚动卡片列表
- 卡片：封面图 + 版本信息 + 启动按钮

交互：
- 横向滚动：平滑滚动，惯性效果
- 卡片悬停：上浮 + 信息展开
- 长按：显示管理菜单
```

### 版本页 (Versions)
```
布局：
- 全屏列表
- 每项：大字体版本号 + 类型标签 + 状态
- 已安装：显示启动按钮
- 未安装：显示安装按钮

交互：
- 点击：展开详情
- 滑动：快速操作（删除/安装）
```

### 设置页 (Settings)
```
布局：
- macOS 系统设置风格
- 分组：游戏、Java、下载、外观
- 每项：标签 + 控件（开关/滑块/输入）

交互：
- 开关：iOS 风格滑动动画
- 滑块：实时预览数值
```

### 账户页 (Accounts)
```
布局：
- 顶部：当前账户大卡片
- 主体：账户列表
- 底部：添加账户按钮

交互：
- 点击切换：卡片翻转动画
- 添加：从底部滑入表单
```

## 动画规范

### 页面过渡
```css
/* 进入 */
@keyframes pageEnter {
  from {
    opacity: 0;
    transform: scale(0.98);
  }
  to {
    opacity: 1;
    transform: scale(1);
  }
}
duration: 300ms
easing: cubic-bezier(0.4, 0, 0.2, 1)
```

### 按钮交互
```css
/* 悬停 */
transform: scale(1.1);
box-shadow: 0 0 60px var(--accent-glow);
duration: 200ms

/* 点击 */
transform: scale(0.95);
duration: 100ms
```

### 卡片悬停
```css
/* 上浮效果 */
transform: translateY(-8px);
box-shadow: 0 30px 80px rgba(0,0,0,0.6);
duration: 300ms
easing: cubic-bezier(0.4, 0, 0.2, 1)
```

### 导航切换
```css
/* 图标弹跳 */
@keyframes navBounce {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(0.8); }
}
duration: 200ms

/* 发光条滑入 */
width: 0 → 24px
duration: 200ms
```

### 启动动画
```
1. 按钮扩展为全屏圆形（300ms）
2. 显示启动日志（从底部滑入）
3. 游戏窗口弹出
4. 启动器淡出到系统托盘
```

## 实现建议

### 推荐依赖
```json
{
  "framer-motion": "^11.x",      // 动画
  "@radix-ui/react-*": "^1.x",   // 无样式组件
  "lucide-react": "^0.x",        // 图标
  "clsx": "^2.x",                // 类名管理
  "tailwind-merge": "^2.x"       // 类名合并
}
```

### 性能优化
- 使用 `will-change` 优化动画元素
- 背景图使用 `transform: translateZ(0)` 开启 GPU 加速
- 玻璃效果在低端设备上降级为纯色背景
