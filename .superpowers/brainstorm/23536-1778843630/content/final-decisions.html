🔀 主题切换：仪式感过渡（1.2s）

切换动画分三个阶段：
① CRT 关机（0.4s）：屏幕正中收缩为一条亮线 → 熄灭。致敬老电视关机。
② 中间态（0.3s）：全屏黑，中央浮现切换控件的物理隐喻——卡带弹出/插入。
③ 新风格展开（0.5s）：如果是侘寂→卡带 = CRT 开机扫描线从上往下扫过；卡带→侘寂 = 纸门从中间向两侧推开。

切换入口：设置面板中的主题卡片 + 快捷键 Ctrl+T。不放在显眼位置，避免频繁切换破坏沉浸感。

📐 通用设计原则（两个主题共有）

原则 决策
布局架构 统一使用底部导航 + 页面切换，两个主题共享相同的组件结构和数据流，只换样式层
动画语言 抛弃 framer-motion 的 spring 弹性动画，改用线性/step-based 过渡。卡带 = 逐行刷新（类似终端输出），侘寂 = 微妙 fade
毛玻璃 全部移除。 AI 味的罪魁祸首。卡带用纯色面板 + 边框，侘寂用纸片阴影
圆角 卡带 = 2px（几乎直角），侘寂 = 1px（刻意不规则）。告别 14px/20px 大圆角
图标 卡带 = 自定义像素图标（16×16 Minecraft 风格），侘寂 = 细线 SVG 图标 + 日本傳統色
动态背景 移除粒子/aurora/waves。卡带 = 静态 CRT 扫描线叠加层，侘寂 = 和纸纤维纹理
排版网格 卡带 = 等宽 8px 基准网格（monospace 天然对齐），侘寂 = 不对称 5/7 分栏（黄金比附近）
原有主题预设 12 套主题预设系统保留但不作为主要卖点，降级为设置中的辅助选项
